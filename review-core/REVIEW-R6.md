# 釣りいこ！ マグロ大作戦 — 実プレイ素材統合

元PNG11枚は提供manifestのSHA256・寸法と一致。旧PNG3枚も保持。新素材の表示用WebP11枚は約640KiBで、外部画像サービスに依存しない。

船体→釣り人下地→肘を軸にした前腕→竿→手前の船縁の順に合成。竿先と糸は同じ手元変換から計算する。魚7種は32分割の連続変形で尾・胸ヒレ周辺を動かし、12フレームをキャッシュする。元画像の左右と関節位置をmanifestから参照。キャッシュは約13MiB。光沢も小さく変化する。低負荷設定では固定フレームにする。

海中背景は水面を起点に一度だけ配置し、下部は深い紺へ連続的に移行する。深場で水面・海底をタイル表示しない。画像取得失敗時は従来の独自描画でプレイを継続できる。

ロゴ変更2c9ff7a・糸とカメラ修正673e81dを含む。タイアップ説明は除去済み。名前とチャンネルリンクは維持。

検査: 320×568・390×844、safe-area 34/21・59/34、初期装備と深場装備のタッチ操作。タイトル→投入→下降→捕獲→巻上げ→釣果→店・図鑑。Canvasに実際に渡した竿先と糸始点を照合。初期3尾・深場8尾の釣果、売上加算、画像失敗時の代替表示を検査。購入・二重購入防止・保存復元・音声開始/休止・旧セーブ互換・帰還時間も既存検査に合格。

連続動画は実ブラウザ録画（無音）。深場装備は既存の成長検査で得た保存データを使用。ゲーム進行自体はタッチ入力で操作している。Windows Chromeのモバイル模擬検査であり、iPhone/TestFlight、低性能端末の実測は未実施。広告・課金・分析SDKの接続は未実施。
